# Project continuity

At each project session start, after meaningful work or changed requirements, and before compaction, handoff or a final reply, read and execute `.agents/skills/work-sync/SKILL.md`. Maintain `handoff/CURRENT.md` and classified events while working; start its watcher and verify a foreground GitHub sync before reporting delivery. Use the existing checkout, with no new worktree unless requested. This repository is authorized for work-sync installation and sanitized project backups to its own origin's `agent-handoff` branch.
